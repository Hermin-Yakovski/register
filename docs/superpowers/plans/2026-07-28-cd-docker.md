# CD with Docker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Docker-based continuous deployment to the CI pipeline, building and pushing images to ghcr.io.

**Architecture:** Extend the existing `ci.yml` with a `cd` job that depends on `ci`. Create a `Dockerfile` using the uv official base image and a `.dockerignore` to keep the image lean. The CD job builds on all events but only pushes to ghcr.io on push to main or version tags.

**Tech Stack:** Docker, GitHub Actions, ghcr.io, uv

WORKDIR /app

# Copy dependency files first for layer caching
COPY pyproject.toml uv.lock ./

# Install production dependencies only

### Task 3: Update CI workflow with CD job

**Files:**
- Modify: `.github/workflows/ci.yml`

- [ ] **Step 1: Add permissions block**

Add the following at the top level of `ci.yml`, after the `on:` block and before the `jobs:` block:

```yaml
permissions:
  contents: read
  packages: write
```

- [ ] **Step 2: Rename workflow**

Change the workflow name from `CI` to `CI/CD`:

```yaml
name: CI/CD
```

- [ ] **Step 3: Add the cd job**

Append the following job after the existing `ci` job:

```yaml
  cd:
    needs: ci
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Log in to GHCR
        uses: docker/login-action@v3
        if: github.event_name == 'push'
        with:
          registry: ghcr.io
          username: ${{ github.actor }}
          password: ${{ secrets.GITHUB_TOKEN }}

      - name: Docker metadata
        id: meta
        uses: docker/metadata-action@v5
        with:
          images: ghcr.io/${{ github.repository }}
          tags: |
            type=raw,value=latest,enable={{is_default_branch}}
            type=semver,pattern={{version}}

      - name: Build and push
        uses: docker/build-push-action@v6
        with:
          context: .
          push: ${{ github.event_name == 'push' }}
          tags: ${{ steps.meta.outputs.tags }}
          labels: ${{ steps.meta.outputs.labels }}
```

- [ ] **Step 4: Verify YAML syntax**

Run: `python -c "import yaml; yaml.safe_load(open('.github/workflows/ci.yml'))"`

If `pyyaml` is not installed, visually verify the file has correct indentation (2 spaces) and valid YAML structure.

- [ ] **Step 5: Commit**

```bash
git add .github/workflows/ci.yml
git commit -m "feat: add CD job to CI workflow for Docker build and push"
```
